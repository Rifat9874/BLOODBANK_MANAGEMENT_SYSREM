Blood Bank Management System
A comprehensive web-based application designed to streamline and manage blood donation and distribution processes efficiently. This system facilitates donor registration, patient management, blood stock tracking, and seamless blood transfer operations.

🚀 Features
User Authentication – Secure login for administrators with role-based access.

Donor Management – Register, view, and manage donor details including personal info and blood group.

Patient Management – Register and track patients requiring blood transfusions.

Blood Stock Dashboard – Real-time tracking of available blood units by blood group.

Blood Transfer Module – Process blood requests from patients and update stock accordingly.

Interactive Dashboard – Overview of key metrics: total donors, transfers, users, and blood stock levels.

Responsive Sidebar Navigation – Easy access to all system modules.
